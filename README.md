# Go1 — задание T4 (оценка движения робота)

Решение задания T4. Это узел на ROS 2, который оценивает, где находится робот и куда он повернут.
Он берет данные из `/imu/data` и `/scan` и отправляет оценку в `/odom` и в TF `odom → trunk`.
Роботом узел не управляет, в `/cmd_vel` ничего не публикует.

## Как работает

Узел 50 раз в секунду (по времени симуляции, в ТЗ нужно не меньше 20) отправляет позу
в `/odom` (`frame_id = odom`, `child_frame_id = trunk`) и ту же позу с тем же временем в TF.

1. Поворот робота берется из IMU (поле `orientation`). IMU стоит в корпусе ровно,
   поэтому его поворот и есть поворот корпуса. Кватернион с NaN или длиной не около 1 пропускается.
2. Положение x, y считается по лидару (20 сканов в секунду). Точки скана переводятся в корпус
   (лидар стоит в точке 0.22, 0, 0.11 от `trunk`) и поворачиваются по IMU, с учетом наклона корпуса.
3. Скан накладывается на карту из прошлых сканов (ICP «точка к прямой»). Поворот уже известен,
   поэтому ищется только сдвиг. Точки с ошибкой больше 2 см учитываются слабее.
4. Карта пополняется, когда робот сдвинулся на 0.2 м или повернулся на 10°.
   Робот все время привязан к стенам и предметам полигона, поэтому ошибка не копится.
5. Если скан не наложился (мало точек, видна только одна стена, сдвиг больше, чем робот может пройти
   за один скан), берется прогноз по последней скорости.
6. Между сканами положение продолжается по скорости. z = 0, робот ходит по ровному полу.
7. NaN и Inf в скане отбрасываются. NaN, Inf и неправильные кватернионы на выход не попадают.
8. Ground truth не используется.

Узел работает до конца испытания: если он упадет, `entrypoint.sh` запустит его снова через 1 с.
При остановке контейнера (SIGTERM) узел останавливается и контейнер завершается.

## Файлы

- `odom/odom.py` — вся логика одометрии
- `odom/icp.py` — карта и наложение скана на карту
- `odom/odom_node.py` — сам ROS 2 узел
- `entrypoint.sh` — запуск контейнера (`ping` или `T4`)
- `Dockerfile` — сборка образа

## Сборка образа

```bash
docker build --platform linux/amd64 -t go1-t4:dev .
```
